# 🎵 Xylophone iOS App

A simple and interactive **Xylophone iOS App** built with **Swift and UIKit**.

The app allows users to play different musical notes by tapping the colorful xylophone keys.

## 📱 Features

* 🎵 Play different musical notes
* 👆 Tap-based interaction
* 🔊 Instant sound playback
* 🎨 Colorful and simple UI
* 📱 Responsive iOS interface
* ⚡ Lightweight and easy to use

## 🛠️ Technologies Used

* **Swift**
* **UIKit**
* **AVFoundation**
* **Storyboard**
* **Auto Layout**
* **Xcode**

## 🏗️ Architecture

The project follows a simple UIKit-based structure suitable for learning and demonstrating basic iOS development concepts.

## 🚀 How to Run

1. Clone the repository.
2. Open the `.xcodeproj` file in Xcode.
3. Select an iPhone Simulator or connected iPhone.
4. Press **Run ▶️**.
5. Tap the xylophone keys to play different notes.

## 🎯 Learning Outcomes

This project demonstrates:

* Handling `UIButton` actions
* Playing audio using `AVFoundation`
* Connecting UI elements with `IBOutlet` / `IBAction`
* Working with Swift functions
* Managing app resources
* Building a basic UIKit application
